# 项目目标

> 个人博客 + AI 智能体搭建项目

## 目标一：个人技术博客

展示技术文章与项目作品，作为个人技术名片。

### 核心功能

- **Markdown 写作**：支持 Markdown 语法，分类/标签体系管理文章
- **代码高亮**：VS Code 级别语法高亮，支持目录导航
- **暗色模式**：明暗主题切换，技术博客标配
- **响应式布局**：PC / 平板 / 手机自适应
- **SEO 优化**：meta 标签、sitemap.xml、robots.txt
- **RSS 订阅**：支持 RSS feed，方便读者订阅

### 交付物

- 博客前端（文章列表、详情页、分类/标签筛选、搜索）
- 内容管理（Markdown 文件管理，便于持续发布）
- 静态 HTML 输出，部署简单、安全、性能好

---

## 目标二：AI 智能体（核心亮点）

网站导览员，基于博客内容回答访客提问，充当智能助手。

### 核心功能

- **RAG 知识库**：将博客文章分块生成 Embedding，存入向量数据库
- **对话式交互**：浮动聊天窗口，支持流式输出（SSE）
- **多轮上下文**：支持追问，基于上一个回答继续深入
- **文章推荐**：回答末尾附上相关文章链接，提升阅读转化
- **高频问题统计**：记录访客高频问题，帮助优化内容方向

### 交付物

- 后端 API 服务（Python + FastAPI）
- RAG 检索引擎（LangChain + ChromaDB）
- 前端聊天组件（React 岛屿，嵌入博客页面）

### 进阶功能（可选）

- **引导式对话**：访客进入网站时主动介绍 AI 助手功能
- **离线留言**：无法回答时记录问题并通知博主
- **访问统计**：分析高频提问，指导内容创作方向
