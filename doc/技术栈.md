# 技术栈

> 分层架构：前端展示 → 智能体后端 → 外部服务 → 基础设施

## 一、前端展示层

| 技术 | 角色 | 说明 |
|---|---|---|
| **Astro** | 博客框架 | 专为内容站点设计，默认输出零 JS 静态 HTML，性能极佳；支持岛屿架构 |
| **Tailwind CSS** | 样式系统 | 原子化 CSS，快速实现自定义设计；响应式、暗色模式开箱即用 |
| **React** | 聊天组件 | 仅用于智能体聊天窗口这一交互组件，不影响博客页面性能 |
| **Framer Motion** | 动画 | 入场动画、聊天消息过渡、滚动揭示效果 |
| **Iconify** | 图标 | 万级图标库，按需引入 |
| **Shiki** | 代码高亮 | Astro 内置，支持 VS Code 级别语法高亮 |

### 设计要素

- 暗色模式（Tailwind `dark:` 前缀）
- 首页 Hero 区域（大标题 + 个人简介 + 智能体入口）
- 文章卡片网格（封面图、标签、阅读时间）
- 浮动聊天按钮（右下角悬浮，点击展开）
- 毛玻璃效果（导航栏和聊天窗 `backdrop-filter`）

## 二、智能体后端层

| 技术 | 角色 | 说明 |
|---|---|---|
| **Python** | 后端语言 | AI 生态最完善 |
| **FastAPI** | API 框架 | 高性能异步框架，自动生成 API 文档 |
| **LangChain** | RAG 框架 | 文档分块、Embedding 生成、检索链编排 |
| **ChromaDB** | 向量数据库 | 轻量本地部署，适合博客文章量级 |

### RAG 流程

```
用户提问 → 向量检索相关文章片段 → 组装 Prompt → 调用 LLM → 返回回答
```

### API 设计

- `POST /api/chat`：接收用户提问，返回流式回答（SSE）
- `POST /api/feedback`：记录用户反馈和高频问题

## 四、基础设施层

| 组件 | 方案 | 说明 |
|---|---|---|
| **云服务器** | 阿里云 ECS 经济型 e 2核2G | 99 元/年，续费同价，新老用户同享；个人账号可购 |
| **Swap** | 2G Swap 文件 | 弥补 2G 物理内存不足，确保智能体后端稳定运行 |
| **Nginx** | 反向代理 + 静态托管 | `/api/*` 代理到后端，其余指向静态博客 |
| **SSL 证书** | Let's Encrypt | 免费证书，certbot 自动申请和续期 |
| **进程守护** | systemd / Supervisor | 管理 Python 后端进程，崩溃自动重启 |
| **域名** | .com | 约 55-75 元/年，在服务器同厂商注册 |

### 服务器选型理由

- 个人账号无法购买企业专享的 ECS u1 2核4G（199元/年），选用经济型 e 2核2G
- **99 元/年续费同价**，新老用户同享，3 年总成本仅 297 元，无续费刺客
- 3M 固定带宽不限流量，博客场景完全够用
- 2G 内存通过添加 2G Swap 补足，可稳定运行 FastAPI + ChromaDB
- 购买入口：https://www.aliyun.com/product/ecs （找到"经济型e 99元"套餐）

### Swap 配置（购买服务器后执行）

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

## 技术选型对比（备选方案）

| 方案 | 设计自由度 | 上手难度 | 适合场景 |
|---|---|---|---|
| **Astro + Tailwind**（选用） | 高 | 中 | 想做独特设计 + 嵌入智能体 |
| VitePress + Vue | 中 | 低 | 快速上线，默认设计好看 |
| Next.js + Tailwind | 最高 | 高 | 前端经验丰富，全动态站点 |
| Hugo + 现成主题 | 低 | 低 | 不想写前端，套主题直接用 |

> 前端代码由 AI 生成，选择 Astro + Tailwind 可最大化设计自由度。
