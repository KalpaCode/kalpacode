## 1. 架构总览

### 1.1 岛屿架构

博客页面默认输出**零 JS 静态 HTML**，全站唯一的动态岛屿是 AI 聊天组件：

```
┌──────────────────────────────────────────────────┐
│  静态层（Astro SSG，无 JS）                        │
│  导航栏 / Hero / 文章索引 / 文章详情 / 归档 / 关于   │
├──────────────────────────────────────────────────┤
│  轻量脚本（< 5KB，原生 TS）                        │
│  主题切换 / 筛选搜索 / TOC 高亮 / 悬浮预览           │
├──────────────────────────────────────────────────┤
│  React 岛屿（唯一 client:load 组件）                │
│  AI 聊天窗（Framer Motion 动画 + SSE 流式渲染）      │
└──────────────────────────────────────────────────┘
```

原则：**能用静态 HTML + CSS 实现的交互（主题、筛选、TOC）就不用 React**，React 只承担聊天窗这一个有复杂状态机的组件。

### 1.2 目录结构

```
src/
├── content/blog/          # Markdown 文章（frontmatter 见 PRD §4.4）
├── layouts/
│   ├── BaseLayout.astro       # <head>、字体、主题初始化脚本、导航、页脚
│   └── PostLayout.astro       # 文章详情骨架（TOC + 正文 + 上下篇）
├── components/
│   ├── Nav.astro              # 毛玻璃导航栏
│   ├── Hero.astro             # 首页 Hero
│   ├── PostIndex.astro        # 文章索引流（含筛选/搜索的轻量脚本）
```

## 2. 页面与路由

| 路由 | 页面 | 组成 |
|---|---|---|
| `/` | 首页 | Hero + 文章索引流（分类筛选 + 搜索） |
| `/posts/:slug` | 文章详情 | 面包屑返回、正文（Shiki 高亮）、TOC、上下篇、Giscus 评论区 |
| `/archive` | 归档 | 按年份分组的文章清单 |
| `/categories/:c` | 分类页 | 该分类下的文章索引 |
| `/tags/:t` | 标签页 | 该标签下的文章索引 |
| `/about` | 关于 | 博主简介、联系方式、站点技术说明 |

### 2.1 首页结构

1. **导航栏**：固定顶部；滚动 > 8px 后启用毛玻璃（`backdrop-filter: blur(16px)` + 半透明底色）；移动端折叠为汉堡菜单。
2. **Hero**：超大字标 `kalpacode` 贴边出血排版（`font-size` 按视口宽度缩放，负字距），下方为中文一句话定位与两个文字型入口：「关于我」「和 AI 助手聊聊 →」（点击唤起聊天窗并聚焦输入框）。
3. **筛选与搜索**：分类以等宽字体文字链接呈现（全部 / 后端 / 前端 / 运维 / AI，各带文章计数），选中项用下划线标记而非色块；搜索框为下划线输入样式，实时过滤。
4. **文章索引流**：不采用卡片网格，采用**编辑式文字流**——每篇文章一行，左侧序号（001/002…），中间大号标题，右侧等宽字体元信息（分类 · 日期 · 阅读时间）。悬停时：行底色填充、双线下划线显现、封面图（或分类色块占位）以浮动预览形式跟随光标。点击进入详情页。
5. **页脚**：© 信息、RSS / GitHub 链接、实时时钟（等宽字体，秒级跳动，Asia/Shanghai）。

### 2.2 文章详情页

- **正文**：最大行宽 44rem 居中，中文正文 16px / 1.75 行高；标题层级拉开字号对比。
- **代码块**：Shiki 高亮（VS Code 配色，亮暗双主题），右上角复制按钮，成功后文字变「已复制」保持 2s。
- **TOC**：桌面端固定右侧，滚动时高亮当前章节，点击平滑滚动；移动端折叠为顶部按钮。
- **图片**：懒加载 + 点击 Lightbox 放大 + 加载失败占位提示。
- **上下篇**：按发布日期取相邻文章，无相邻时不渲染对应位置。
- **评论区**：Giscus（GitHub Discussions），空评论时显示引导文案。

## 3. 设计系统（Design Tokens）

全部令牌以 CSS 变量定义在 `tokens.css`，Tailwind 通过 `theme.extend.colors` 引用同名变量，保证明暗切换只改变量不改类名。

### 3.1 色彩

亮色为暖调纸面基底 + 品牌紫单点强调，暗色为纯反转（不是简单的灰色替换）：

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#f4f4f2` | `#0a0a0a` | 页面基底（暖白 / 近黑） |
| `--bg-alt` | `#f0efed` | `#121212` | 区块交替底 |
| `--surface` | `#ffffffcc` | `#161616cc` | 毛玻璃表面（导航/聊天窗，含透明度） |
| `--text` | `#0a0a0a` | `#f4f4f2` | 主文字 |
| `--text-2` | `#737373` | `#a3a3a0` | 次要文字（元信息） |
| `--text-3` | `#171717` | `#e5e5e2` | 强调文字 |
| `--border` | `#e5e5e5b3` | `#262626b3` | 细分隔线 |
| `--row-hover` | `#e6e6e6` | `#1a1a1a` | 索引行悬停填充 |
| `--accent` | `#4b3fe3` | `#7a6ff0` | 品牌主色（暗色提亮一档保证对比度） |
| `--accent-deep` | `#1a1759` | `#b3abf5` | 深紫（阴影/按下态） |

约束：

- 全站**只有 `--accent` 一个彩色**，不使用渐变、不使用第二种强调色；分类色块占位图从品牌紫的同色相明度阶梯派生。
- 正文对比度 ≥ 7:1（`--text` on `--bg`），次要文字 ≥ 4.5:1。
- 主题初始化脚本内联在 `<head>`，读 localStorage / `prefers-color-scheme`，**杜绝闪烁（FOUC）**。

### 3.2 字体

| 角色 | 字体栈 | 规格 |
|---|---|---|
| 展示（拉丁字标） | `'Archivo', 'Inter', system-ui`（`font-display: swap`） | Hero 字标 `clamp(4rem, 13vw, 12rem)`，字重 800，字距 `-0.03em` |
| 中文标题 | `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"` | 字重 700；**禁用 `font-style: italic`**（中文无真斜体） |
| 正文 | `system-ui, "PingFang SC", "Microsoft YaHei", sans-serif` | 16px / 1.75 |
| 等宽（元信息/序号/时钟/代码） | `ui-monospace, "SF Mono", "Cascadia Code", Consolas, monospace` | 11–12px，全大写，字距 `0.18em` |

中英混排规则：拉丁展示字体永远放在中文回退之前，确保中文由系统中文字体渲染。

### 3.3 间距与布局

- 内容最大宽度：索引流 72rem（左边距桌面端 8rem 起），正文 44rem。
- 间距阶梯：`4 / 8 / 16 / 24 / 40 / 64 / 96px`，不取中间值。
- 索引导航、筛选、元信息全部使用**文字 + 下划线**，不使用圆角按钮、卡片嵌套、左侧色条等装饰性框架。

### 3.4 动效

统一缓动与时长，禁止各自为政：

| 场景 | 参数 |
|---|---|
| 微交互（悬停、聚焦、开关） | `0.2s cubic-bezier(0.44, 0, 0.56, 1)` |
| Hero 入场 | 逐词/逐字 stagger（间隔 40ms），`translateY(1em) → 0` + 透明度，时长 0.6s |
| Logo 轨道点 | 12s 匀速自转（`transform: rotate`），`prefers-reduced-motion` 时静止 |
| 索引行悬停预览 | 封面以 `translate3d` 跟随光标，0.15s 线性跟手 |
| 聊天消息 | Framer Motion：进入 `opacity + y:8px`，0.2s；流式输出逐字追加 |
| 主题切换 | `color/background-color 0.3s`，禁用过渡期间的全局 `*` 过渡 |

全局遵守 `prefers-reduced-motion`：所有入场/位移动效降级为透明度变化。

## 4. 核心组件规格

### 4.1 文章索引流（PostIndex）

- 数据：构建期从 `content/blog` 读取 frontmatter，按日期倒序注入 `data-*` 属性（分类、标签、标题拼音首字母、摘要）。
- 筛选/搜索为纯前端过滤：分类单选 + 关键词匹配标题/摘要/标签（支持拼音首字母），命中行显示、未命中 `display:none`，无跳页。
- 空状态：显示「没有匹配的文章」+ 「问问 AI 助手 →」（点击唤起聊天窗并预填搜索词）。
- 阅读时间：`Math.ceil(正文字数 / 400)` 分钟，构建期写入。

### 4.2 AI 聊天窗（ChatWidget，React 岛屿）

**状态机**（与 PRD §4.3 状态流转一致）：

```
collapsed ──点击悬浮球/Hero 入口──▶ expanded ──发送──▶ waiting ──SSE 首字──▶ streaming
   ▲                                                                  │
   └────────────── 点击 × / 页面跳转 ◀── idle ◀──流式结束──────────────┘
```

- **悬浮球**：右下角 56px 圆形，使用 Logo 纯图标版；未读欢迎语时轨道点旋转提示。
- **面板**：380px 宽、毛玻璃（`backdrop-filter: blur(16px)` + `--surface`），头部为等宽字体标题 `AI GUIDE — KALPACODE` + 清空/关闭按钮。
- **首启**：欢迎语 + 3 个建议问题（冷启动用博主预设，后续取自 `/api/feedback` 高频问题）。
- **消息流**：用户消息右对齐、AI 消息左对齐；AI 回答句末上标引用来源文章；回答结束后下方附「相关文章」行（≤2 条，序号 + 标题 + 链接）。
- **会话**：sessionId 存 localStorage，历史保留最近 20 条；「清空」重置。
- **降级**：>15s 未收到首字或连续 3 次失败 → 展示「AI 助手暂时休息中」+ 检索原文片段；10 分钟内不再调用 LLM。
- **频控**：前端做 ≤10 次/分钟的客户端节流，超限提示「休息一下再问」。

### 4.3 与后端的接口约定

```
POST /api/chat
Content-Type: application/json
{ "sessionId": "uuid", "question": "...", "history": [{"q","a"} × ≤5] }

→ 200 text/event-stream
data: {"type":"delta","text":"…"}        # 逐字
data: {"type":"sources","posts":[{"title","url"}]}
data: {"type":"done"}
data: {"type":"degraded","text":"…"}     # 降级原文片段
```

```
POST /api/feedback
{ "sessionId": "uuid", "question": "...", "resolved": boolean }
```

## 5. 内容契约（frontmatter）

与 PRD §4.4 一致，Astro Content Collections 用 Zod 校验：

```yaml
---
title: 文章标题          # 2-60 字，必填
date: 2026-08-15        # 必填
category: 后端           # 枚举：后端/前端/运维/AI，必填
tags: [Docker, 网络]     # 0-5 个，每个 ≤10 字
cover: /images/xx.jpg   # 可选，≤2MB，16:9 推荐；缺省用分类色块
summary: 一句话摘要      # 可选，≤120 字；缺省截正文前 120 字
draft: false            # true 不发布
---
```

## 6. 性能预算与工程约束

| 指标 | 预算 | 手段 |
|---|---|---|
| 首页首屏 | ≤ 2s（3M 带宽） | 零 JS 静态 HTML；聊天岛屿 `client:idle` 延迟水合 |
| 首屏 JS | ≤ 60KB（gzip，不含聊天岛屿） | 主题/筛选脚本手写，不引框架 |
| 聊天岛屿 | ≤ 120KB（gzip） | React + Framer Motion 分包，空闲加载 |
| 字体 | 仅拉丁子集，中文用系统字体 | `unicode-range` 子集化 + `font-display: swap` |
| 图片 | 懒加载 + Astro `<Image>` 自适应 srcset | 封面统一裁 16:9 |
| SEO | meta / OG / sitemap.xml / robots.txt / RSS | `@astrojs/sitemap` + `@astrojs/rss` |
| 可访问性 | 对比度、焦点可见、`prefers-reduced-motion`、聊天窗 `role="dialog"` | 走查清单纳入验收 |
