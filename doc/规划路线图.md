# 规划路线图

> 五阶段搭建计划，预计总工期 9-21 天 + 持续运维

## Phase 1：基础设施准备

**工期**：3-7 天（备案审批时间另算）

### 任务清单

- [ ] 注册域名（.com 约 55-75 元/年，推荐阿里云/腾讯云）
- [ ] 购买云服务器（阿里云 ECS 经济型 e 2核2G，99 元/年，续费同价）
- [ ] 提交 ICP 备案（大陆服务器必须，7-20 个工作日）
- [ ] 域名解析（A 记录指向服务器公网 IP）
- [ ] 服务器初始化（安装 Nginx、配置防火墙、SSH 密钥登录）
- [ ] 配置 2G Swap（弥补 2G 物理内存，确保智能体运行稳定）

### 注意事项

- 备案与博客开发可并行推进，购买服务器后第一件事就提交备案
- 新用户优先抢秒杀价（38-68 元/年），但务必查看续费价格
- 香港/海外节点可免备案，但访问速度稍慢

---

## Phase 2：博客开发部署

**工期**：2-5 天

### 任务清单

- [ ] 初始化 Astro 项目 + Tailwind CSS 配置
- [ ] 挑选/设计博客主题（技术博客风格，代码高亮、目录导航、响应式）
- [ ] 规划内容结构（分类：后端/前端/运维/AI，标签体系）
- [ ] 配置 SEO（meta 标签、sitemap.xml、RSS、robots.txt）
- [ ] 实现暗色模式切换
- [ ] 本地编译生成静态文件
- [ ] 部署到服务器（scp/rsync 上传 + Nginx 配置站点）
- [ ] 配置 SSL 证书（Let's Encrypt + certbot 自动续期）

### 交付物

- 可访问的博客网站（HTTPS）
- 文章列表页、详情页、分类/标签页
- 响应式布局适配

---

## Phase 3：智能体开发（核心阶段）

**工期**：3-7 天

### 任务清单

- [ ] 选择大模型方案
  - 方案 A（推荐）：调用国内大模型 API（通义千问/DeepSeek）
  - 方案 B：使用 Coze/Dify 平台零代码搭建
  - 方案 C：本地部署开源模型（Ollama + Qwen2）
- [ ] 构建知识库（博客 Markdown 文章分块，生成 Embedding 存入 ChromaDB）
- [ ] 实现 RAG 流程（用户提问 → 向量检索 → 组装 Prompt → 调用 LLM → 返回回答）
- [ ] 开发 API 服务（FastAPI `/chat` 接口，支持流式输出 SSE）
- [ ] 开发前端聊天组件（React 岛屿，浮动聊天窗）
- [ ] 集成到博客页面

### 注意事项

- 服务器为 2核2G + 2G Swap，智能体后端常驻运行需注意内存占用
- FastAPI + ChromaDB 常驻内存约 300-500MB，加上 Swap 共有 4G 可用空间，足够稳定运行
- 设置每日 token 上限，加入缓存机制（相同问题不重复调用），控制月费 10-30 元
- 知识库同步：发布新文章后自动更新向量数据库

---

## Phase 4：部署上线

**工期**：1-2 天

### 任务清单

- [ ] Nginx 反向代理配置（`/api/*` → 后端，其余 → 静态博客）
- [ ] 进程守护配置（systemd / Supervisor 管理 Python 后端）
- [ ] CDN 配置（Cloudflare 或腾讯云 CDN 免费额度）
- [ ] 图床配置（GitHub + jsDelivr 或对象存储 OSS/COS）
- [ ] 全面测试
  - 博客页面加载速度
  - 移动端适配
  - 智能体对话流畅度
  - API 响应时间

---

## Phase 5：运维与持续优化

**工期**：持续进行

### 任务清单

- [ ] 配置服务器资源监控（宝塔面板或 Uptime Robot 免费监控）
- [ ] 配置 GitHub Actions 自动部署（push 代码 → 自动编译 → 部署到服务器）
- [ ] 知识库自动同步（发布新文章后更新向量数据库）
- [ ] 数据备份（cron 脚本定期备份到对象存储）
- [ ] SEO 优化（提交百度/Google 站长平台）
- [ ] 接入评论系统（Giscus 或 Waline）
- [ ] 接入网站统计（百度统计或 Google Analytics）
