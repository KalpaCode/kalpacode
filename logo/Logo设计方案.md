## 1. 设计理念

### 1.1 品牌名解读

- **Kalpa**（梵语 कल्प）：意为"劫波"，宇宙的一个纪元，代表漫长的时间与永恒
- **Code**：代码、编程
- 组合含义：**用代码记录跨越时间的技术思考**

### 1.2 设计方向

方案 B：**K + 轨道**——字母 K 作为核心字标，3D 透视轨道环环绕 K，形成"土星环"式立体效果。

### 1.3 设计演进

| 阶段 | 方案 | 结论 |
|---|---|---|
| 初轮 | 4 个方向（括号字标 / K+轨道 / 语法字标 / 极简单字） | 选定方案 B K+轨道 |
| K 字形态 | 6 个变体（线条几何 / 括号融合 / 负空间 / 粗细对比 / 一笔连写 / 点阵） | 选定变体5 一笔连写 |
| 轨道形态 | 平面椭圆包含 K → 立体穿叠环绕 | 选定 3D 土星环穿透 |
| AI 生成 v1 | 笔画过粗，连笔感丢失 | 作废 |
| AI 生成 v2 | 细化笔画 + 恢复连笔 + 3D 穿叠 | 带文字版确认 |
| 裁切版 | 从确认版裁掉文字，保留图标 | 确认 |

## 2. 视觉规格

### 2.1 字母 K

| 参数 | 值 |
|---|---|
| 形态 | 一笔连写（calligraphic brushstroke） |
| 主笔路径 | 底部起笔 → 向上画竖干 → 转折斜向右下收笔（不抬笔） |
| 上臂 | 从竖干中段分支，斜向右上（独立短笔） |
| 描边宽度 | 中等（约 5-6px / 200px 画布） |
| 线帽 | round（圆角） |
| 线条连接 | round（圆角） |
| 风格 | 流动、优雅，非几何块状 |

### 2.2 轨道环

| 参数 | 值 |
|---|---|
| 形态 | 扁平椭圆（透视视角，模拟土星环） |
| 比例 | rx:ry ≈ 2.4:1（rx=90, ry=38 / 200px 画布） |
| 倾斜 | -15°（逆时针） |
| K 与环关系 | K 高度 90 > 环高度 76，K 上下穿透环面 |
| 远端弧（后方） | 细线 1.8px，渐变峰值 opacity 0.35，画在 K 后方 |
| 近端弧（前方） | 粗线 4px，渐变峰值 opacity 1.0，画在 K 前方 |
| 深度投影 | 近端弧下方 +1.5px 偏移，暗色 opacity 0.12 |
| 渐变方向 | 水平方向，中心最浓（离观察者最近/最远），两端渐淡 |
| 轨道点 | 实心圆，位于环右上角，r=5px |

### 2.3 渲染图层顺序

```
① 远端弧（后方）→ ② K 连笔 → ③ 近端弧投影 → ③ 近端弧（前方）→ ④ 轨道点
```

### 2.4 色彩

| 元素 | 色值 | 用途 |
|---|---|---|
| 品牌主色 | `#4B3FE3` | K 字、近端弧、轨道点 |
| 远端弧 | `#4B3FE3` opacity 0.35 | 后方轨道（退晕） |
| 投影色 | `#1A1759` opacity 0.12 | 近端弧下方阴影 |
| 背景 | `#FFFFFF` | 纯白底 |
| 文字 | `#4B3FE3` | "kalpacode" 小写无衬线 |
